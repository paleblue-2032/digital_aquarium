# digital_aquarium

手で描いた魚をスキャンして、そのまま泳がせるデジタル水槽。もともとは
「スキャナー → Python のフォルダ監視サーバー → OpenCV で切り抜き → p5.js で表示」
という構成でしたが、**サーバーを不要にして全部ブラウザの中で完結**するように作り直しました。
[kanon-server.com](https://github.com/paleblue-2032/homepage) の `others/` に埋め込んで使っています。

## できること

- 描いた魚の絵を読み込むと、背景を自動で切り抜いて透明な魚スプライトにする
- 魚は泳ぎ回り、泡をつつると浮かび上がる
- クリック（マウス/タッチ）で餌をまく。餌を追いかけて食べる
- 水槽は 10 分で 1 日が巡る（時間帯で明るさが変化）
- 追加した魚は一定時間で泳ぎ去る（デフォルトの魚は残る）

## 遊び方の分岐

最初に開いたときに 2 つのモードから選べます。

| モード | 餌やり | 魚の追加 |
| --- | --- | --- |
| マウスで遊ぶ | クリック / タッチ | 画像ファイルのアップロード（ドラッグ&ドロップ可） |
| Arduino・スキャナーを使う | Arduino のジョイスティック（Web Serial） | カメラでスキャン（画像アップロードも可） |

ハードウェアが無くても動きます。Arduino を繋がない場合はマウス操作にフォールバックします。

### Arduino 側

9600 baud で 1 行ずつ次の形式を送るだけです（改行区切り）。

```
STICK,<x>,<y>,<touch>\n
```

- `x`, `y` は `-30..30` の範囲
- `touch` は押下中が `0`、離した瞬間に餌をまく（元の仕様を踏襲）

## 構成

```
index.html        水槽ページ（others から相対パスで参照）
style.css         ページの見た目（サイトの配色トークンに合わせています）
script.js         p5 スケッチ + ブラウザ内画像処理 + 入力/ハードウェア分岐
lib/p5.min.js     p5.js 1.9.0（CDN ではなく同梱）
assets/           デフォルトの魚スプライトと泡の効果音
samples/          動作確認用の入力例
tools/process_fish.py   オフラインで一括処理したい人向けの CLI（サーバーではない）
flake.nix         Python ツールチェーンの再現用
```

## オフライン処理（任意）

ブラウザだけで完結するので、普段この CLI は使いません。スキャナーで溜めた画像を
まとめて変換したいときだけ使います。ツールチェーンは Nix flake で固定しています。

```sh
nix run .#process -- samples/ -o out     # samples/ の画像を out/ に変換
nix develop                              # 開発シェル（process-fish, ruff 入り）
process-fish scans/ -o out --watch       # フォルダを監視して変換（明示的に指定したときだけ）
```

## 開発

`nix develop` で入るか、`opencv-python` `numpy` `pillow` を入れた Python で
`tools/process_fish.py` を直接叩いてください。ブラウザ側は静的ファイルなので
`python -m http.server` などで配信すれば確認できます。
